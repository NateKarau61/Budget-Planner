Budget Planner

Everyone keeps their own budget using the 50/30/20 rule (or your own split): 50% needs, 30% wants (your fun money), 20% savings & debt. Pick a page below, then add yourself to get started.

Two completely separate ways to track a budget — log every expense on Transactions, or just type one number per category on Quick totals. Switch anytime; they don't share numbers.

Who's budgeting? separate, private budgets per person

Save & load your data no account needed — everything stays in this file

This tool doesn't save anything automatically. Click Save budgets to file before you close it, and use Load budgets from file next time to pick up where you left off. One file holds everyone's data on both pages — each person's budget stays separate, and Transactions and Quick totals stay separate from each other too.

Data lives only in this open tab and in files you save — nothing is uploaded anywhere. The 50/30/20 split is a common guideline, not a rule; adjust category targets to fit your own situation.
